Security & privacy
What this app reads, what it never sends, and what the operator must protect.

Read-only by design

The container reads a mounted HAProxy log or accepts syslog. It has no upload endpoint, database or account system. The optional persistent syslog history writes only to the dedicated data volume; everything else stays in memory.

No third-party requests

The page loads only same-origin CSS, JavaScript, SVG and JSON. There are no CDNs, external fonts, analytics, telemetry, map tiles or IP-lookup services. A strict Content Security Policy blocks outbound connections.

HAProxy provides TLS and authentication

The app intentionally has no login. Compose binds the port to 127.0.0.1 by default. Put HAProxy in front, terminate TLS there and require authentication before proxying to the app. Do not expose the app port directly.

Logs are sensitive

Visitor IPs, SNI hostnames, requested paths, status codes and timestamps can reveal user behaviour and internal topology. Treat screenshots, exports and browser history as sensitive. Define retention and access rules before deployment.

Viewer IP detection

/api/whoami reports the connecting peer. X-Forwarded-For is honoured only when the immediate peer is in TRUSTED_PROXIES. Never trust arbitrary forwarded headers; configure only the address of your reverse proxy.

GeoIP is approximate

MaxMind locations are estimates, not device positions. Private, documentation and reserved addresses are not located. The dashboard must keep working without a GeoIP database; geography simply becomes unavailable.

Syslog receiver

The optional receiver is off by default. When enabled it has a source-network allowlist, bounded buffers and optional TLS with client certificates. Prefer a private network or a TLS relay; plain syslog has no authentication.
